# STRUCTURA — Digital Architecture Studio

>A digital architecture studio landing page showcasing scalable web systems, design systems expertise, and a philosophy of structural discipline.

## Overview

STRUCTURA is a modern, responsive landing page for a digital architecture studio. The site presents the studio's philosophy, selected projects, process, design systems capabilities, testimonials, and a contact form. The design emphasizes clarity, scalability, and a strong visual hierarchy, with support for both light and dark themes.

## Features

- **Responsive Design:** Adapts seamlessly to all screen sizes.
- **Theme Toggle:** Switch between light and dark modes.
- **Animated UI:** Smooth entrance animations and interactive elements.
- **Scroll Progress Indicator:** Visual feedback for page scroll progress.
- **Back to Top Button:** Quick navigation for long pages.
- **Mobile Navigation:** Hamburger menu for mobile devices.
- **Contact Form:** Simulated form submission with success feedback.
- **Accessible:** Keyboard navigable and color contrast aware.

## Sections

- **Hero:** Studio tagline and call-to-action buttons.
- **Philosophy:** Four pillars of the studio's approach.
- **Selected Work:** Highlighted case studies with project tags.
- **Process:** Timeline of the studio's workflow.
- **Design Systems:** Capabilities in design tokens, component libraries, and motion principles.
- **Testimonials:** Client feedback and endorsements.
- **Contact:** Form for project inquiries.
- **Footer:** Studio info, navigation, and social links.

## Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, responsive grid, and animations
- **JavaScript (ES6)** — UI interactivity and state management

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. All assets are local; no build step is required.

## Customization

- Update content in `index.html` to reflect your studio or business.
- Adjust styles in `styles.css` for branding or color changes.
- Enhance interactivity or connect the contact form to a backend in `script.js`.
